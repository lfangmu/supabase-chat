广播签名密钥生成器（Ed25519）

生成本项目「消息广播防伪造」所需的 Ed25519 密钥对。全程在你的浏览器本地运行，私钥不上传任何服务器。 生成后请把私钥填到 Supabase、公钥填到 Cloudflare——两者必须配对，缺一不可。





部署步骤：
  1. 复制私钥：Supabase 项目 → Edge Functions → broadcast-message → Secrets，新增 BROADCAST_SIGNING_KEY = 私钥（推送后函数会自动重新部署）。
  2. 复制公钥：Cloudflare Pages → 你的项目 → Settings → Build → Build variables（构建环境变量），新增 NEXT_PUBLIC_BROADCAST_VERIFY_KEY = 公钥（需重新构建生效）。
  3. ⚠️ 公钥必须填到 Cloudflare：前端内联的默认公钥与你的私钥不匹配，不填会导致广播校验失败、消息被丢弃。
